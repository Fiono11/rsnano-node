\section{Related Work}
\label{sec:related}
Guerraoui et al.\ characterize asset transfer's consensus number, including the single-owner case~\cite{consensusnumber}. FastPay provides prefunded Byzantine settlement without a global transaction order~\cite{fastpay}; Astro builds asynchronous payments on broadcast~\cite{astro}; Zef adds private coin payments~\cite{zef}; Nano provides account-local chains with distinct send and receive operations~\cite{nano}. These establish the application-level opportunity, not RAI's transition rules. Astro's extended version discusses asynchronous replica reconfiguration with view-tagged messages and account-log transfer~\cite{astro,dbrb}; RAI's distinction is the frozen-report evidence that preserves first- and final-vote obligations across a boundary while the next epoch is already voting.

Sui Lutris uses consensus for shared objects and checkpoint sequencing, including end-of-epoch handling of processed certificates~\cite{lutris}; RAI does not continuously sequence ordinary certificates, so there is no certificate sequence to drain before the epoch ends. Cuttlefish broadens the fast path with collective objects and FastUnlock~\cite{cuttlefish}; RAI's boundary promotion is narrower. Pastro studies permissionless asynchronous asset transfer with weighted stake and a dynamic adversary~\cite{pastro}; Dynamic Byzantine Reliable Broadcast and asynchronous Byzantine reconfiguration address broader changing-participation settings~\cite{dbrb,reconfiguration}. PDCC combines certificate-based payments with membership change and periodic settlement; its installation rule accepts certificates for the installed configuration and states a correct-member overlap assumption~\cite{pdcc}, whereas RAI preserves eligible old-domain certificates assembled later and needs no members common to consecutive committees.

Consensus with external validity is a standard interface~\cite{externalvalidity}; RAI uses it with the eligibility predicate of Section~\ref{sec:manifest} and instantiates it with a leader-based voting construction~\cite{simplex,kudzu}. Authenticated set reconciliation is a mature building block~\cite{iblt,whatsthedifference,rateless}. Model checking small configurations of Byzantine protocols with TLC is common practice~\cite{tla}; here it served as a regression test for the handoff rules rather than as a proof.
